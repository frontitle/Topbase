仪表盘小组件开放能力

把支持嵌入的 HTTPS 页面放进仪表盘。作者可以直接填写运行地址，也可以从小组件库选用开发者注册的预设。

接入方式

  1. 将组件页面部署到 HTTPS 地址，并允许 Topbase 所在站点通过 iframe 嵌入。
  2. 在仪表盘编辑工具栏点击“插入”，切换到“添加小组件”，选择“自定义组件”。
  3. 在选中组件的设置栏中输入完整的组件地址。

通过地址配置组件

运行地址和网格位置随卡片保存。可以添加组件约定的查询参数，例如将倒计时组件的 unit 设为 day 或 hour。在组件页面中读取参数即可决定显示内容。

// 倒计时组件页面内
const params = new URLSearchParams(location.search);
const unit = params.get('unit') === 'hour' ? '小时' : '天';
document.querySelector('[data-unit]').textContent = unit;

下面的预设使用 ?unit=day。作者可以在某张卡片的组件地址中将它改为 ?unit=hour。画布每次加载这张卡片时，都使用保存的地址。

在小组件库中提供预设

维护 Topbase 部署的开发者可以在编辑器宿主页面加载 dashboard-widgets.js 之后运行以下代码，将示例地址替换为实际组件地址。注册后，预设出现在“添加小组件”的“嵌入与扩展”分组中，可按名称搜索、点击或拖入画布。

TopbaseDashboardWidgets.registerPlugin({
  id: 'delivery-countdown',
  label: '交付倒计时',
  url: 'https://widgets.example.com/countdown/?unit=day',
  w: 6, h: 4
});

id 在目录中唯一，以小写字母开头，可包含小写字母、数字和连字符。w 和 h 的范围分别为 2–24 格和 2–48 格，默认尺寸为 12 × 10 格。每次插入都会生成独立卡片。查看、分享和嵌入页面直接读取卡片保存的运行地址。

适配卡片大小

iframe 会跟随卡片缩放。在组件内部使用响应式布局，紧凑尺寸优先显示核心内容。需要重新绘图时，可使用 ResizeObserver 监听组件容器尺寸。

预留的宿主通信协议

当前版本用隔离 iframe 运行组件。浏览器将沙箱页面标记为不透明来源，而宿主要求消息匹配组件网址的来源。因此 topbase.dashboard.ready、topbase.dashboard.context 和 topbase.dashboard.set-config 目前仅为预留协议。注册参数中的可选 config 只会复制进卡片记录。组件需要读取的初始选项请放在运行地址中。
