仪表盘小组件开放能力

将任意 HTTPS 页面作为 Topbase 仪表盘组件运行。组件通过隔离 iframe 加载，并以 postMessage 与宿主交换受限的展示上下文和自身配置。

组件不会获得 Topbase 登录态、页面 DOM 或仪表盘原始数据。数据建模与分析应在 Topbase 分析中完成；小组件仅负责呈现和自身交互。

接入方式

  1. 将组件部署到可通过 HTTPS 访问的地址，并允许被 iframe 嵌入。
  2. 在仪表盘编辑模式中打开“添加小组件 → 自定义组件”，输入运行地址。
  3. 组件应适配容器大小；用户可在画布中拖拽、调整尺寸。

可先使用内置的 可运行示例组件 验证接入流程。

宿主上下文

iframe 加载后，宿主会发送 topbase.dashboard.context。组件也可先发送 topbase.dashboard.ready 请求重发。

window.addEventListener('message', (event) => {
  if (event.data?.type !== 'topbase.dashboard.context') return;
  const { state, theme, locale, card, config } = event.data.payload;
  // state: config | view | fullscreen
  render({ theme, locale, config, size: card.layout });
});

window.parent.postMessage({ type: 'topbase.dashboard.ready' }, '*');
字段说明
stateconfig 为编辑预览，view 为呈现，fullscreen 为画布全屏。
theme当前画布主题：deep、aurora、light。
card组件 ID、名称和画布布局；不得视为权限或数据访问凭据。
config该组件专属、由组件自己保存的 JSON 配置。

保存组件配置

仅在 config 状态下，组件可请求保存自身配置。宿主会校验消息来源与组件运行地址的同源关系。

window.parent.postMessage({
  type: 'topbase.dashboard.set-config',
  config: { title: '本月销售', accent: '#20b8f2' }
}, '*');

开发要求

  • 使用响应式布局；建议在较小容器中隐藏次要元素。
  • 配置变更应实时刷新预览。
  • 兼容三种主题和全屏状态。
  • 不要将任何从宿主收到的信息转发给第三方服务；组件自身的数据请求须明确告知用户。
  • 不要依赖 Topbase 内部 DOM、Cookie 或私有接口。
