开发仪表盘小组件

小组件是嵌入仪表盘的 HTTPS 页面，可用网址添加，也可注册为预设。

添加组件

  1. 部署 HTTPS 页面，并允许 Topbase 站点通过 iframe 嵌入。
  2. 在仪表盘编辑器选择「插入 → 添加小组件 → 自定义组件」。
  3. 在卡片属性中填写完整网址。

传入参数

网址和位置随卡片保存。例如，在组件网址加上 ?unit=hour，即可按小时显示倒计时。

const params = new URLSearchParams(location.search);
const unit = params.get('unit') === 'hour' ? 'h' : 'd';
document.querySelector('[data-unit]').textContent = unit;

注册预设

在编辑器加载 dashboard-widgets.js 后注册组件，将示例网址替换为实际地址。预设会显示在「嵌入与扩展」中。

TopbaseDashboardWidgets.registerPlugin({
  id: 'delivery-countdown',
  label: 'Delivery countdown',
  url: 'https://widgets.example.com/countdown/?unit=day',
  w: 6, h: 4
});

id 须唯一，以小写字母开头，仅含小写字母、数字和连字符。w 和 h 分别为 2–24 和 2–48 格，默认 12 × 10。每张卡片独立保存。

适配尺寸

iframe 随卡片缩放。使用响应式布局；需要重绘时，可用 ResizeObserver 监听尺寸。

宿主通信

沙箱 iframe 使用不透明来源，无法通过宿主的消息来源校验。 topbase.dashboard.ready、topbase.dashboard.context 和 topbase.dashboard.set-config 为预留消息。可选的 config 仅存入卡片；组件需要读取的初始值请放在网址参数中。
