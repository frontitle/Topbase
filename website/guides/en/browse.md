# Browse tables and export results

Open Source data, select the database and then the table. Inspect its fields and preview a few rows. If an expected field is missing after a database change, ask an administrator to rescan the table. If the whole table is missing, verify the source and group permissions.

## Inspect and export a selection

Filter the table to a known period or category before querying. Compare a sample identifier with the source record. For a saved analysis, open its result and use the export action. Supply the same filters and SQL parameters used for the on-screen result. Check the exported column names and reporting period before distributing the file.
