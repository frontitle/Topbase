# Arrange cards and connect filters

Open a dashboard and choose Edit. Use Insert → Add analysis for a saved result, or Add widget for a heading or explanatory text. Put related totals and trends near one another so readers can compare the same period.

## Position and preview

Drag a card to move it. Use its resize handle to change its footprint. While dragging, press Escape to cancel. Select the card to adjust its properties. Preview the canvas and check that long labels and table columns still fit.

## Check a linked filter

Add a dashboard filter and map it to compatible fields on the cards it should affect. For a channel selector, target the channel field on both the total and trend analyses. Select one channel in preview and compare both cards with the filtered source analysis. Clear the selection to restore the full view.
