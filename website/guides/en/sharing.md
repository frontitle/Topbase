# Share or embed a dashboard

Open Share on the dashboard. Public sharing must be enabled by an administrator, and the person publishing the link needs permission to manage the dashboard. A public link gives visitors access to the published canvas.

## Set access conditions

Choose a permanent link, a duration such as seven days, or a specific deadline. Set a password before publishing if visitors must verify access. Copy the link and open it in a signed-out browser. Verify the password prompt and a chart with real data.

## Embed, renew or revoke

Enable embedding and copy the iframe snippet into the destination page. The embed uses the same password and expiry rules. To extend access, change the expiry on the existing link. To withdraw access, disable the public link and revisit it as a guest.
