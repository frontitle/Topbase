# Run a SQL analysis

Choose New analysis → Use SQL or AI, then select the source database. The SQL editor uses that database’s dialect. Start with a small read-only query against a table you can browse and limit the rows while checking field names.

## Parameters and results

For a parameterized query, supply the requested values before running or exporting. Check that changing the date range changes the results. Give calculated columns recognizable aliases before saving. If native queries are unavailable, ask an administrator to check the group’s SQL permission for this source.
