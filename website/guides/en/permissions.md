# Groups and permissions

Create a group for the team sharing an analysis. An administrator adds members and grants the group access to the required sources. Configure the ability to browse tables, run native SQL and manage content according to the work each member performs.

## Verify access as a member

Save an analysis into the intended data group. Sign in as an ordinary member, open that group and run the analysis. Then open the dashboard that uses it and verify its cards. When someone can find a dashboard but a card fails, check the underlying analysis and source permissions as well as dashboard access.
