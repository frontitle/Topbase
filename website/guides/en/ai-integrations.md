# Explore data with MCP and the CLI

An administrator enables developer mode and provisions API access. Configure your client with the Topbase server address and the key for the intended account. Use an account with access to the sources you want to analyze.

## Ask a verifiable question

Start by listing available tables and inspecting field names. Ask for paid order value by sales channel for a specific month. Inspect the selected table, payment filter, date interval and aggregation before confirming creation of a saved analysis. Open the analysis in Topbase and compare its total with the source table.
