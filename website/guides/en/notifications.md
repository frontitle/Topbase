# Subscribe to a dashboard or set an alert

Use a subscription for a recurring report. Use a result alert when delivery depends on a value crossing a condition. Before configuring either, verify that the dashboard contains the metric and time range recipients expect.

## Configure delivery

An administrator configures the delivery channel in Integrations. Select the provider, enter the webhook details and use the test action to verify the destination. On the dashboard open More → Subscribe to dashboard, choose the channel and schedule, then save.

## Check a threshold

Open More → Set result alert and choose the target metric and condition. Check the threshold against the metric’s stored unit. If a message is missing, inspect the delivery channel, schedule and latest analysis result before editing the condition.
