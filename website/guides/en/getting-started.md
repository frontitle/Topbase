# Build your first sales dashboard

Start with an orders table containing an order date, sales channel and amount. Decide whether each row represents an order or an item. Counting rows gives different answers in those two cases.

## Connect the data

Ask an administrator to [import a workbook](excel.html) or [connect a database](database-drivers.html). Open the table in the data browser and check several records. Make sure amount is numeric and the date column contains the period you want to report.

## Answer one question

Create an analysis using the orders table. Filter the date to your reporting period, sum the amount and group by sales channel. Run the query. Check the table first, then switch to a bar chart and save it as **Sales by channel** in a group your team can access.

## Present the result

Create a dashboard, open Edit and insert the saved analysis. Resize the card until all channel labels fit. Open Preview and compare the values with the analysis. When they match, use [sharing](sharing.html) to give a colleague access.
