# Describe fields in the data model

In Admin, open the data model, select a source and table, then inspect the fields alongside their database types. Give unfamiliar names a business description. For example, explain whether an amount includes refunds and whether an order date records creation or payment.

## Field meaning and visibility

Choose a semantic type that reflects how a field is used. An identifier that happens to contain digits is a category, while an amount can be aggregated. Review visibility and masking for sensitive fields. Open the table as a regular user and inspect field names, formatting and sample values after saving.
