# 选择与配置图表

同一条查询既可以比较各渠道销售额，也可以展示渠道占比。前者适合柱状图，后者适合环形图。以下操作使用[可视化分析](analysis.html)中得到的三行渠道汇总结果。

## 把渠道销售额画成柱状图

1. 在 **分析** 列表中打开「Sales by channel」，等待结果加载。拥有编辑权限时，结果区上方会出现图表类型，旁边会出现 **设置** 面板。
2. 选择 **柱状图**。在 **数据** 中，将 **横轴** 设为 `channel`，**纵轴** 设为金额汇总列。可视化求和结果列为 `sum`，使用 [SQL 示例](sql.html)时则选择 `revenue`。
3. 在 **显示** 中勾选 **显示数值**。假设每个渠道的销售目标为 200，勾选 **目标线**，目标值输入 **200**，标签填「渠道目标」。Web 为 300，高于目标线；Partner 为 200，恰好达标；Store 为 180，低于目标线。
4. 在 **坐标轴** 中，将纵轴标题改为「已支付销售额」。如果金额有明确币种，可在标题里写上单位。图表设置会自动保存。重新打开分析核对显示效果，再将它添加到[仪表盘](dashboards.html)。

当结果中包含另一列分类字段，并且只有一个指标时，可通过 **添加分组** 将指标拆成多个系列。如果查询返回多列数值，则可以在没有额外分组时使用 **添加指标**。要查看各组内部不同系列所占的比例，可在堆叠设置里选择百分比。

## 显示各渠道销售占比

在已保存分析上选择 **饼图**。进入 **数据**，**维度** 选 `channel`，**指标** 选金额汇总列。在 **显示** 中勾选 **环形图** 和 **显示总计**，将 **显示百分比** 设为 **图例**，**百分比小数位** 设为 **1**。

总计应为 **680**，其中 Web 占 **44.1%**，Partner 占 **29.4%**，Store 占 **26.5%**。**最多分类** 和 **最小切片占比 %** 控制哪些较小的类别会归入「其他」。示例中保留默认的 8 个分类上限，最小占比取 0，可看到全部三个渠道。切换图表类型会更新当前分析。要同时保留柱状图和环形图，可从数据表查询编辑器另存一条新的分析。

## 根据业务问题选择图表

| 读者想看什么 | 查询要返回什么 | 图表及配置 |
| --- | --- | --- |
| 一个已支付销售总额 | 一行数值，示例为 680 | 选 **数字** 并指定总额字段。**数值对比** 可选择同一结果中的另一列数值。 |
| 每周或每日走势 | 每个日期或自然周一行，并有对应数值 | 选 **折线图** 或 **面积图**，横轴为时间，纵轴为指标，核对日期顺序。 |
| 名称很长的分类排行 | 每个分类一行，按金额排序 | 选 **条形图**，横向条形旁可以放较长的类别名。 |
| 各日期或类别的观测值 | 一列维度和一列数值指标 | 选 **散点图**，把每个观测值显示为一个点。将指针移到点上，可与表格中的数值核对。 |
| 精确值和订单号 | 包含所需字段的逐笔明细 | 选 **表格**，在显示设置中勾选要展示的列、修改列标题。 |
| 不同地区的分布 | 区域字段及每个区域的数值合计 | 选 **地图**，指定图资包、区域字段和数值字段。中国省级图资包可识别 `广东`、`广东省`、`440000` 等值。 |

## 图表与预期不一致时

先切回 **表格** 查看实际返回的行和列名。若横轴显示了一串订单号，回到查询中按渠道或日期分组。若金额没有出现在指标列表，检查源值是否带有货币符号或以文本保存，让查询返回数值类型。修改查询后，特别是更改过 SQL 别名时，重新核对横纵轴字段。
