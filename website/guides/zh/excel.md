# 上传并预览 Excel 工作表

管理员可以把电子表格导入本地数仓，保存一份副本，并在 Topbase 核对明细。下载[示例工作簿 orders.xlsx](../assets/samples/orders.xlsx)跟着操作，完成后应看到一张包含六行、五个字段的订单表。

## 整理工作簿

| 检查项 | 导入规则 |
| --- | --- |
| 格式与大小 | 支持 `.xlsx` 和 `.xlsm`。上传大小应小于 20 MB。旧版 `.xls` 文件请先另存为 `.xlsx`。 |
| 工作表顺序 | 将要导入的工作表移动到第一个标签页并保存。「上传 Excel」会自动读取第一张工作表。 |
| 表头 | 第一行每列填写一个字段名。移除报表标题、合并表头及空列。表头范围内的空名称会按位置命名，如 `字段2`。重复字段会加后缀，如 `amount_2`。 |
| 数据行 | 从第二行起，每行一条记录。全空行会跳过，最多导入前 100,000 个非空数据行。超过时应先拆分文件。 |
| 单元格 | 导入后按文本保存。每个要保留的数据列都应有表头。移除不应作为记录导入的合计行和脚注。 |

## 上传第一张工作表

1. 使用管理员账号进入「管理后台 → 数据」。在页面顶端从「远程数据源」切换到「本地数仓」。
2. 点击「上传 Excel」，在文件选择框选中刚下载的 **orders.xlsx**。选定文件后即开始导入。
3. 在本地数仓列表找到 **orders**。数据集名称取自文件名。卡片应显示来源文件 **orders.xlsx**、工作表 **orders**、**6 行**和 **5 个字段**。
4. 点击「预览记录」。找到订单 **1003**，核对其 `amount` 为 **50**、`status` 为 **refunded**，确认表头与单元格没有错位。

## 读懂预览并修正导入结果

卡片上的行数是已导入记录数。预览最多展示前 50 行和前 50 个字段。单元格内容很长时，可能提前达到 128 KiB 的预览大小上限。核对大表是否完整时，请看卡片上的总行数。

| 看到的情况 | 如何处理 |
| --- | --- |
| 导入的是另一张工作表 | 将目标表移动到第一个标签页，保存工作簿后重新上传。 |
| 报表标题变成了字段名，或数据错列 | 将真正的字段名放在首行，拆掉合并单元格，检查每行数据的列顺序。 |
| 列表里出现了两个同名数据集 | 每次上传都会创建独立副本。可给修订文件换个名字，重新上传并预览，确认无误后用「删除」移除旧副本。删除操作仅清理 Topbase 内的导入数据。 |
| 想对这些订单做 SQL 查询或制图 | Excel 导入结果可在本地数仓预览。查询编辑器和 SQL 使用已连接的数据库。下载[同一批订单的 SQLite 文件](../assets/samples/orders.db)，按[创建第一张销售仪表盘](getting-started.html)继续。 |
