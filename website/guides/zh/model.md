# 在数据模型中说明表和字段

看到 `amount` 时，读者需要知道其中是否包含已退款订单。管理员可以在 Topbase 中为表和字段添加业务说明、易读的别称和语义类型，让使用者在查询前就能确定统计口径。

## 打开元数据编辑器

1. 进入 **管理后台 → 数据模型**。配置示例数据库时，选择 **远程数据源**，在 **数据源** 下拉框选 **Sales orders**，搜索并点击 `orders`。这里的远程数据源包括通过连接添加的数据库，例如示例 SQLite 文件。配置上传的 Excel 数据集时，请选择 **本地数仓**，再选导入后的数据集。
2. 管理员也可以在 **源数据** 中打开一张已连接的表，点击 **编辑元数据** 直达对应的数据库、schema 和表。先核对编辑器上方显示的物理名称。
3. 将 **表显示名称（别称）** 填为「订单明细」。在 **业务备注** 中填写「每行代表一笔订单。金额包含全部状态，统计已支付销售额时请筛选 status 为 paid。」工作台优先显示业务备注，编辑器里也可以查看源数据库的表注释。
4. 输入后稍候，让自动保存完成。重新打开该表，核对别称和备注。字段较多时，可点击字段列表上方的 **全屏编辑**，按 **Esc** 返回。

## 为字段设置业务含义

**物理名** 和 **类型** 来自源数据。通过可编辑的 **别称**、**字段说明** 和 **语义**，记录每个字段适用的场景。以下是一套适合示例订单表的填写方式。

| 物理名 | 别称 | 语义 | 字段说明 |
| --- | --- | --- | --- |
| `order_id` | 订单编号 | 主键（实体标识） | 唯一标识一笔订单，可用于核对单条记录。 |
| `order_date` | 下单日期 | 创建日期 | 记录订单创建的自然日。 |
| `channel` | 销售渠道 | 分类 | 值为 Web、Partner 或 Store。按此字段分组可比较渠道。 |
| `amount` | 订单金额 | 金额（货币） | 该订单的金额，包括状态为已退款的记录。 |
| `status` | 支付状态 | 分类 | 统计已支付销售额时，筛选值为 paid 的记录。 |

字段修改会自动保存，切换数据表前先等待保存提示。语义类型描述字段的业务含义。如果源表把金额存成了文本，需调整输入类型或在 SQL 中返回数值，再进行求和。

## 描述两张表的关联

如果数据库中另有一张渠道对照表 `channels`，找到 `orders.channel` 的字段行，语义选 **外键**。在 **外键表** 中填 `channels`，在 **外键字段** 中填 `channel`，两项都使用目标的物理名称。核对对照表中的渠道键是否唯一、订单中的渠道值是否能匹配。此后在[可视化查询](analysis.html)里打开 **关联数据** 时，已知关系可用于预选匹配字段。

## 设置可见性并验证

表标题旁的眼睛图标控制整张表在前台的可见性，每行字段上的眼睛图标控制该字段的可见性。要恢复显示，在 **数据模型** 中选中同一对象，再次点击眼睛。手机号、电子邮箱等敏感语义会在下拉菜单中标出「默认脱敏」。对底层数据的读取权限应在[权限管理](permissions.html)中配置。

返回 **源数据** 重新打开示例表，检查是否能看到「订单明细」和业务备注，再到结果预览中核对列名「订单金额」。写 SQL 时继续使用物理字段名 `amount`。如果刚新增的字段没有出现在编辑器中，先在数据源管理中同步结构，再重新打开该表。
