# 公开分享或嵌入仪表盘

打开仪表盘，在顶部点击 **分享**，可以向访客提供只读视图。先用成员账号查看一次仪表盘，确认准备公开的卡片与数据范围。例如，只向合作伙伴展示渠道汇总时，检查画布上是否还包含订单明细。

## 创建有效期七天的链接

1. 工作区管理员进入 **管理后台 → 设置 → 访问与安全 → 对外访问**，允许仪表盘公开链接并保存。访客需要从外网访问时，在 **设置 → 访问与安全 → 域名与 SSL** 中配置对外访问地址。
2. 使用能管理该仪表盘的账号打开 **分享**，打开 **公开分享**。一周复盘可选 **7 天**。有效期还可选择永久、1 天、30 天，或按本地时间指定未来的截止时间。
3. 如需密码，勾选 **需要访问密码**，输入 8 至 128 个字符，再点击 **开启分享**。复制随后出现的 **公开链接**。
4. 用无痕窗口打开链接。如有密码，输入后核对一张图表与登录状态下的数据。发送给访客的是这里复制的公开链接，后台编辑地址供工作区成员使用。

## 修改有效期、密码或停止分享

再次打开 **分享**，修改期限或密码并保存。更换密码的输入框留空会保留原密码。要取消密码要求，去掉勾选并保存。已过期的链接也可以设置新的截止时间，访客继续使用原地址。

需要收回访问时，关闭 **公开分享** 并确认撤销链接。用无痕窗口重新访问原链接，确认仪表盘已无法打开。使用该链接的嵌入也会失效。

## 嵌入外部页面

工作区管理员先在 **设置 → 访问与安全 → 对外访问** 允许嵌入到外部页面。回到仪表盘，先发布仍在有效期的公开链接并保存当前设置，再由管理员打开 **允许 iframe 嵌入**。复制 iframe 代码，粘贴到目标页面支持 HTML 嵌入的位置。保留其中的访问地址，按目标页面调整宽度和高度。

以访客身份打开目标页面。嵌入视图使用同一密码与有效期。开关不可用时，检查管理员身份、工作区策略、链接期限以及当前分享设置是否已保存。链接只有服务器本机能打开时，检查对外访问地址和访客网络连通性。
