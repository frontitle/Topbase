# 筛选、汇总与关联

从「分析 → 新建分析」选择数据表或已保存分析。先看几条明细，再决定输出字段。核对数据粒度时保留标识列，方便判断同一对象是否出现多次。

## 筛选与汇总

以各渠道已支付销售额为例，先筛选支付状态和订单日期，再选择金额求和、按渠道分组，最后按汇总金额降序排列。行数统计衡量数量，金额求和衡量收入。取消分组运行一次，核对总额是否等于各渠道之和。

## 关联与计算字段

要按客户类别查看销售额，可以客户 ID 关联订单表和客户表。先确认客户表中每个 ID 只出现一次，再对比关联前后总额。按商品明细计算收入时，可以先用自定义列计算数量乘以单价，再对结果求和。

## 保存与复用

运行分析后设置便于识别的名称并选择数据组。编写 SQL 时，选择对应数据库并使用具备原生 SQL 权限的账号。将结果放入仪表盘前，检查返回的字段名和数据类型。
