# 让团队成员查看仪表盘

权限分组包含人员，团队数据组保存分析、仪表盘等内容。要让销售同事查看一张仪表盘，先把人加入权限分组，配置这组人的能力，再为他们授予仪表盘所在数据组的角色。

## 添加人员并授予项目角色

1. 管理员打开 **管理后台 → 人员与组**（`/admin/people/`）。若对方还没有本地账号，先点 **添加成员**，填写姓名和邮箱。
2. 点击 **新建分组**，命名为「Sales readers」（销售只读组），再点 **创建分组**。切换到 **权限分组** 标签，在该组的卡片上点击 **管理分组**。
3. 在 **分组成员** 中选择一个普通成员，按下表设置四项工作区能力。系统组和同步组的成员由各自的来源维护。
4. 在同一窗口找到标有 **数据组 · 项目名** 的下拉框，为销售仪表盘所在项目选择 **查看**。每个已有团队数据组各有一项，可选 **不授予、查看、编辑、管理**。
5. 点击 **保存分组配置**。重新打开 **管理分组**，核对成员、全局权限与项目角色。内置管理员组具有固定权限。

## 四项权限如何选择

| 设置项 | 可选级别 | 销售只读组示例 |
| --- | --- | --- |
| 数据浏览 | 无访问、可浏览、可管理 | 可浏览 |
| SQL 查询 | 禁止、可查询、可使用原生 SQL | 需要使用可视化查询的成员选择可查询 |
| 内容与数据组 | 无访问、可查看、可编辑 | 可查看 |
| 后台管理 | 无、允许进入管理后台 | 无 |

若还需要一组负责制作图表的作者，在其分组的 **内容与数据组** 中选择 **可编辑**，为目标项目选择 **编辑**，需要 SQL 编辑器时选择 **可使用原生 SQL**。调整分组能力或项目角色后点击 **保存分组配置**。

## 接入企业通讯录或第三方登录

1. 打开 **管理后台 → 人员与组 → 账号与身份接入**，点 **接入企业组织**，选择飞书，填写接入名称。点 **继续配置**，填应用的 App ID 和 App Secret，再点 **验证并接入**。在飞书中，应用的通讯录授权范围需覆盖准备同步的部门。
2. 点 **同步组织**，查看返回的部门数，再打开权限分组列表。内置同步为每个返回的飞书部门创建分组，按飞书 Open ID 匹配已有 Topbase 成员。部门已出现但成员为空时，先核对账号绑定与应用通讯录范围，然后重新同步。
3. 例如打开同步得到的「销售部」分组，为它授予销售项目的 **查看** 角色。成员关系由飞书维护。接入表单另有「部门到权限分组的映射」字段，接受逗号分隔的 `外部部门ID:Topbase分组ID`。本版同步实际更新自动生成的部门组，授权后应在这些组中核对成员。
4. 平台列表也提供钉钉、企业微信，这个发行版尚未包含它们的组织同步适配器。向群聊发消息的 Webhook 可在[通知与订阅](notifications.html)中独立配置。

个人登录在 **添加第三方登录** 中设置。选择 **Google** 或 **微信开放平台**，填写显示名称及客户端凭据，验证接入后检查 **允许的登录方式**，至少保留一种。先配置 Topbase 对外域名，OAuth 回调路径为该域名下的 `/auth/oauth/PROVIDER_ID/callback`，其中 ID 取自 Topbase 登录链接中的接入标识。在个人中心或成员操作菜单中绑定身份，然后用独立会话实际登录，确认能够访问自己的项目，再调整其他登录方式。

## 用成员账号验证

在独立浏览器会话中用刚添加的普通成员登录，进入销售数据组，打开仪表盘并检查卡片是否加载，再实际操作一次预期允许的功能。如果可用权限超出预期，检查该成员所属的全部分组（包括「所有人」）以及项目角色。看不到仪表盘时，核对其实际保存位置与该项目的授权。能看到仪表盘但卡片无数据时，再检查来源分析与数据的读取权限。
