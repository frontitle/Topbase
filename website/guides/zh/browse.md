# 浏览数据表与导出结果

想核实某个销售数字，可以先打开数据表，找到参与计算的订单，检查每行记录，再把查询保存起来供以后导出 CSV。

## 打开一张表

1. 在工作台打开 **源数据**。按连接名称搜索数据库，点击对应卡片。首次使用可先准备[入门指南](getting-started.html)中的示例数据库。
2. 在左侧 **搜索表** 中输入表名、别称或字段名。表按数据库的 schema 显示。选择 `orders`，在 **数据** 区核对 schema 和物理表名。
3. 等待查询编辑器下方显示返回行数。打开表时会执行一次只读预览，默认最多返回 1,000 行。大表预览显示 1,000 行，表示本次已返回的行数。要统计全表记录数，清空筛选和分组，选择 **汇总 → 记录数** 后运行。

在 **源数据** 中运行查询时，Topbase 实时读取已连接的数据库。管理员上传的 Excel 工作表有单独的预览入口，在 **管理后台 → 数据 → 本地数仓**。想跟随本页步骤查询那批工作表记录，可连接示例 SQLite 数据库。详见[上传并预览 Excel 工作表](excel.html)。

## 核对单个渠道的订单明细

1. 在 **可视化查询 → 数据** 中展开字段列表，勾选 `order_id`、`channel`、`amount`、`status`，取消其他字段。
2. 在 **筛选** 中添加两个条件：`channel` 等于 `Web`，`status` 等于 `paid`。**计算** 保持 **不汇总**，点击 **运行并预览**。
3. 查看结果中的订单号和金额。示例数据中，这些订单的金额之和为 **300**。要在数据库中复核，可将 **计算** 改为 **求和**，选择 `amount`，保持不分组，再次运行。
4. 如果要导出逐笔订单，保存前切回 **不汇总** 并重新运行。要按固定顺序导出，可设置 **排序**。数据量较大时，先核对 **行数限制**，再判断本次查询是否包含全部符合条件的记录。

## 把已保存的结果导出为 CSV

1. 点击 **保存分析**，命名为「Web 渠道已支付订单」，选择有写入权限的分组并确认。后续可以从 **分析** 列表重新打开。
2. 在分析详情页点击 **导出 CSV**，Topbase 会重新运行已保存的查询。如果刚在详情页临时更改了筛选，导出前会提示使用已保存的筛选条件。要永久改变导出范围，点击 **编辑**，修改查询，重新运行并保存。
3. 打开下载文件，核对表头和订单号。此例中每条记录都应满足 `channel = Web` 和 `status = paid`。导出带参数的 SQL 分析时，会使用填写的参数值。详见 [SQL 分析](sql.html)。

## 找不到表、结果或下载文件

- **列表里没有表。** 核对数据库和 schema，清空搜索。请管理员检查表的可见性及当前用户组的数据访问权限。
- **看得到表名，预览却失败。** 远程数据库不可用时，页面仍可能显示缓存的表结构。管理员可测试数据源连接。如果刚新增或修改了字段，可同步表结构后再打开。
- **能打开分析，导出时提示无权限。** 导出会重新运行查询。请管理员检查数据访问权限，若为 SQL 分析，还要检查原生 SQL 权限。如果提示登录过期，重新登录后再次导出。
