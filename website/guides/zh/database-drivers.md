# 连接数据库并检查表结构

管理员需准备数据库类型、网络地址、库名和账号。给连接账号授予分析所需表的读取权限。SQLite 使用文件路径，Topbase 进程必须能读取该文件。

## 测试连接

进入「管理后台 → 数据 → 远程数据源 → 添加数据库」。选择驱动并填写连接信息，需要加密时配置 SSL。通过跳板机访问时，在连接信息中填写数据库内网地址，在 SSH 页签中填写跳板机信息。点击「测试连接」，成功后保存。

## 找不到需要的表时

打开已保存的数据源并同步结构，选中数据表查看字段。源表字段变化后可单独点击「重新扫描此表」。连接成功但找不到表时，核对库名，以及连接账号对目标 schema 的读取权限。
