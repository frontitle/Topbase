BUILT FOR OWNERSHIP

Run Topbase on your own servers

Your team controls the application database, connection keys, saved analyses and dashboards.

Read the installation guide
Docker Compose
git clone --branch v__VERSION__ \
  https://github.com/frontitle/Topbase.git
cd Topbase
cp -n .env.example .env
chmod 600 .env
openssl rand -base64 32

On first install, open .env in a text editor. Set TOPBASE_APP_DB_PASSWORD to a strong, unique password and paste the OpenSSL output into TOPBASE_MASTER_KEY. Save the file before starting Compose. Keep the same .env when restarting or upgrading.

docker compose -f docker-compose.release.yml up -d

Once the services are ready, open http://YOUR_SERVER:8101 in your browser.
