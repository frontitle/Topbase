自托管部署

在自己的服务器上运行 Topbase

Topbase 默认面向自托管场景。应用数据库、连接密钥、分析资产和仪表盘都由团队自己掌握。

阅读部署与备份文档
Docker Compose
git clone --branch v__VERSION__ \
  https://github.com/frontitle/Topbase.git
cd Topbase
cp -n .env.example .env
chmod 600 .env
openssl rand -base64 32

首次安装时，用文本编辑器打开 .env。给 TOPBASE_APP_DB_PASSWORD 设置独立的强密码，把 OpenSSL 输出的一整行填入 TOPBASE_MASTER_KEY。保存文件后再启动 Compose。重启和升级时沿用这份 .env。

docker compose -f docker-compose.release.yml up -d

服务就绪后，在浏览器打开 http://服务器地址:8101。
