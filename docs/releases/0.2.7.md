# Topbase 0.2.7

## English

The website, guide screenshots and bilingual user manuals now live in the [website repository](https://github.com/frontitle/frontitle.github.io/tree/main/Topbase). The product repository contains the application, deployment files, tests and contributor documentation.

For a new installation, clone the release with `git clone --depth 1 --branch v0.2.7 https://github.com/frontitle/Topbase.git`. The [installation guide](https://frontitle.github.io/Topbase/docs/installation.html) covers Docker Compose and building directly on a server.

For an existing Docker installation, fetch and check out `v0.2.7`, then set `TOPBASE_VERSION=0.2.7` in the existing `.env`. Verify the image tag with `docker compose -f docker-compose.release.yml config --images` before pulling and restarting. The application database uses schema 19.

## 简体中文

官网、教程截图和中英文用户手册现由[官网仓库](https://github.com/frontitle/frontitle.github.io/tree/main/Topbase)独立维护。产品仓库包含应用源码、部署文件、测试和贡献者文档。

新安装请使用 `git clone --depth 1 --branch v0.2.7 https://github.com/frontitle/Topbase.git` 下载本版源码。[安装指南](https://frontitle.github.io/Topbase/zh/docs/installation.html)提供 Docker Compose 和服务器直装两种方式。

已有 Docker 安装请先获取并切换到 `v0.2.7` 标签，在现有 `.env` 中设置 `TOPBASE_VERSION=0.2.7`，用 `docker compose -f docker-compose.release.yml config --images` 核对镜像标签，再拉取并重启。应用数据库使用 schema 19。
