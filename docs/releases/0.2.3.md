# Topbase 0.2.3

发布日期：2026-08-30

0.2.3 是部署与发布可靠性补丁版本：正式 GHCR 镜像改为公开下载，安装说明覆盖服务器直接运行与 Docker Compose，同时修复发版后容器回归测试仍校验旧版本号的问题。

## 升级前必须确认

1. 备份应用数据库或完整 SQLite 数据目录，并保留原 `TOPBASE_MASTER_KEY`。
2. 确认当前部署使用的外部端口：Docker 默认是宿主机 `8101`，直接运行默认是 `80`。
3. 不要执行 `docker compose down -v`，该命令会删除 Compose 命名卷。

本版本不新增 migration，应用数据库 Schema 仍为版本 14，可从 0.2.2 直接滚动升级。

## Docker 升级

GHCR 镜像已经公开，不需要执行 `docker login ghcr.io`：

```bash
git fetch --tags
git checkout v0.2.3
export TOPBASE_VERSION=0.2.3
docker compose -f docker-compose.release.yml pull
docker compose -f docker-compose.release.yml up -d
```

默认访问地址是 `http://服务器IP:8101`。如需其他宿主机端口，在 `.env` 中设置 `TOPBASE_HTTP_PORT` 后重新执行 `up -d`。

## 服务器直接升级

```bash
git fetch --tags
git checkout v0.2.3
make check
make build
```

使用原有应用数据库、数据目录和 `TOPBASE_MASTER_KEY` 重启服务。直接运行默认监听 `:80`；可以通过 `TOPBASE_PORT` 或 `TOPBASE_ADDR` 保持现有端口。

## 验收清单

- `docker pull ghcr.io/frontitle/topbase:0.2.3` 无需登录即可成功；
- `/api/ready` 返回 `status: ready` 和 `schema_version: 14`；
- `/api/version` 返回 `version: 0.2.3`；
- 重启容器或进程后，管理员、数据源、分析和仪表盘仍然存在；
- 分享、嵌入与 OAuth 回调继续使用后台配置的外部协议、域名和端口。
