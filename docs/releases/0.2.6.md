# Topbase 0.2.6

## English

- The installer documentation now covers the server and Docker paths in English and Chinese. The Docker guide keeps backups outside the checkout, sets the target image version explicitly and verifies the running version.
- The Excel preview places its close button next to the worksheet title. The bilingual feature guides show the release interface with the six-order sample.
- Source builds use the public Go module path `github.com/frontitle/Topbase`. The container includes third-party license notices and builds from a restricted file set.
- Security reports can go directly to the maintainers through [GitHub private reporting](https://github.com/frontitle/Topbase/security/advisories/new).

[Install Topbase](https://frontitle.github.io/Topbase/docs/installation.html)
