# Security policy

English · [简体中文](SECURITY.zh-CN.md)

## Report a vulnerability

Use GitHub's [private vulnerability report form](https://github.com/frontitle/Topbase/security/advisories/new) while signed in. Reports go to the Topbase maintainers. Keep technical details in the private report while the maintainers investigate and coordinate a fix.

Include the affected version or commit, installation method, expected and observed behavior, and the impact. Use a minimal example with synthetic data. Redact passwords, connection strings, API keys, session cookies and customer records from attachments.

## Supported versions

During early development, fixes are released on the current development line. Report issues affecting the latest public release or the default branch, and include the exact version so maintainers can reproduce them. [Latest release](https://github.com/frontitle/Topbase/releases/latest)
